# ADR-004: MCP Implementation Deferred

**Status:** Accepted  
**Date:** 2026-08-31

## Context

MCP control plane is important but the current priority is documentation foundation and clear architecture.

## Decision

No MCP servers, Omni Router MCP, or Mega MCP construction/redesign will be performed in the current phase. Only the future integration boundary is documented.

## Consequences

- docs/MCP_CONTROL_PLANE.md remains the high-level intent document.
- Any MCP-related tasks are marked 🚫 OUT OF SCOPE until a later explicit decision.
