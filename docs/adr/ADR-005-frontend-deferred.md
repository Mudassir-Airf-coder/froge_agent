# ADR-005: Frontend / Design Work Deferred

**Status:** Accepted  
**Date:** 2026-08-31

## Context

The project is focused on architecture, flow, tasks, bootstrap, agents, tools, health, recovery, and documentation.

## Decision

No design.md, UI, or frontend work in the current phase.

## Consequences

- Any request for design.md or UI is out of scope until architecture and core contracts are complete.
